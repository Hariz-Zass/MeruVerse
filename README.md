# MeruVerse

Smart Green Meru Raya — interactive urban dashboard for Bandar Meru Raya, Ipoh, Perak.

## Live dashboard

https://meruverse.vercel.app

## Project direction

- Futuristic smart and green urban interface
- Place search and map-focused location information
- Nearby business/place details
- Daily news section
- Healthy living, nature, and smart technology

## Source status

The existing live deployment is hosted on Vercel. Its complete source files and image assets have **not yet been imported into this repository**. This repository currently contains project documentation only. Do not connect it to automatic production deployment until the source is transferred.
